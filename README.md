# ⚽ Sorteio De Baixa Conduta PRO CLUBS

Site para sortear times equilibrados pelo nível (estrelas) de cada jogador — tema FIFA Pro Clubs.

## 🔗 Acesse o site

**👉 https://caioluiz-ads.github.io/sorteio-baixa-conduta/**

Abre em qualquer aparelho: celular, tablet ou computador. É só mandar esse link pros colegas de time.

## 🎮 Funcionalidades

- ➕ **Adicionar jogador** com nome, foto, nível em estrelas (com opção de **meia estrela** ⭐) e estatísticas de **gols** e **assistências**.
- 👥 **Elenco** com a lista de todos os jogadores, foto ao lado e estatísticas.
- 🎲 **Sorteio de times equilibrado** — distribui os jogadores de forma que a soma de estrelas de cada time fique o mais parecida possível (de 2 a 6 times).
- 💾 **Backup / Restaurar** — salve seus jogadores em um arquivo e recupere quando quiser, em qualquer dispositivo.

## 💡 Observações

- Os jogadores ficam salvos automaticamente no **navegador de cada aparelho** (o armazenamento não é compartilhado entre celulares diferentes). Para levar os dados de um aparelho para outro, use os botões **Salvar backup** / **Restaurar backup**.
